Data Analytics Programming course provided valuable understanding and practical experience in programming for data science, data analysis, and machine learning using Python. Throughout the course, knowledge of Python programming, built-in data structures, functions, NumPy, Pandas, data cleaning, data wrangling, data aggregation, visualization, and introductory machine learning techniques was significantly strengthened through lectures, active learning activities, and hands-on programming exercises. Practical exposure using Jupyter Notebook and Python enhanced analytical thinking, programming, and problem-solving skills while improving the ability to manipulate, analyse, and visualize data effectively for real-world applications. In addition, the project-based learning activities and presentations strengthened communication, teamwork, and technical reporting skills through the development and presentation of data analytics projects. The course also increased understanding of how statistical techniques, machine learning, and data visualization support data-driven decision-making in modern industries. Overall, this course successfully enhanced both theoretical understanding and practical competency in data analytics programming and data science applications.
