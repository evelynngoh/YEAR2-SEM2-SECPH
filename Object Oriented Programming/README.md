Object Oriented Programming course provided valuable understanding and practical experience in object-oriented concepts and Java application development using the Java programming language. Throughout the course, knowledge of classes and objects, encapsulation, inheritance, polymorphism, arrays, collections, exception handling, UML class diagrams, and Java APIs was significantly strengthened through lectures, tutorials, laboratory exercises, quizzes, and project-based learning activities. Practical exposure to Java programming enhanced programming, analytical thinking, and problem-solving skills while improving the ability to design and develop both text-based and GUI applications using object-oriented approaches. In addition, the mini project and presentation activities strengthened teamwork, communication, and collaboration skills through the development of medium-scale Java applications in groups. Exposure to software tools such as Java SDK, Visual Studio Code, and UML diagram tools also increased understanding of structured software development practices in real programming environments. Overall, this course successfully enhanced both theoretical understanding and practical competency in object-oriented programming and Java application development.
