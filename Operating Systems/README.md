Operating Systems course provided valuable understanding of the fundamental concepts, structures, and management techniques used in modern operating systems. Throughout the course, knowledge of process management, process synchronization, deadlocks, memory management, virtual memory, file systems, storage management, and operating system structures was significantly strengthened through lectures, active learning activities, laboratory exercises, and project-based learning. Practical exposure to Linux and Unix environments, including process-related operations and file management, enhanced technical competency, analytical thinking, and problem-solving skills while improving understanding of how operating systems manage computer resources and concurrent processes efficiently. In addition, the group project, demonstrations, and laboratory assessments strengthened teamwork, communication, and critical thinking skills through collaborative development of operating system simulations and algorithm-based case studies. The course also increased understanding of the relationship between computer hardware and operating system services in supporting efficient system performance and resource allocation. Overall, this course successfully enhanced both theoretical understanding and practical competency in operating system concepts and system-level computing.
